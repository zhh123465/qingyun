# 青云小程序 · 前端视觉优化方案

> 版本：v1.0 ｜ 日期：2026-10-24 ｜ 状态：待评审
> 适用范围：`pages/` 全部 26 个页面、`components/tab-bar`、`app.wxss` 全局样式

---

## 一、优化方向决策（已定）

### 选定方向：**「青绿校园 · 编辑式排版」—— 黑体为骨，图形元素为魂**

不推倒重来。现有设计唯一的确定性品牌资产是 **青绿主色（#10A56A）**——截图中的"书法体"实为评审设备的系统字体效果，其他用户看到的是系统黑体，**不构成品牌资产，方案不依赖它**。

品牌辨识度改由三类**确定性元素**承担（不随用户系统字体变化）：

1. **编辑式排版**：大字号粗黑标题 + 字间距控制 + 大字距小字标签（`letter-spacing`），参考 Awwwards 编辑式版式
2. **图形记忆点**：手绘墨笔触 SVG（tab 下划线、分隔装饰）、云纹渐变（封面、空状态、身份卡）——全部是可绘制的图形，与字体无关
3. **色彩体系**：青绿主色 + 宣纸米白（--paper）+ 语义色分工

"普通感"不来自风格选错，而来自执行不完整。优化围绕三个词展开：

| 关键词 | 含义 | 解决的问题 |
| --- | --- | --- |
| 立骨 | 建立严格的 Token 体系（字阶/圆角/阴影/间距网格），杜绝拍脑袋数值 | 页面之间质感不统一、圆角随意 |
| 破平 | 用双层投影、渐变封面、状态色打破"全是平贴白卡"的现状 | 视觉层级平、像线框图上色 |
| 活化 | 补按压反馈、进入动画、骨架屏、空状态插画 | 界面"死"，操作无回应 |

### 品质基准

**以 Awwwards / Webby Awards / FWA 获奖级网站为品质标准。** 小程序虽有平台约束（无自定义光标、无 WebGL 自由发挥、rpx 体系），但获奖级作品的核心素养——排版精度、留白节奏、视觉层级、动效编排、细节原创性——完全可迁移。本方案的每一个页面都按此标准执行，而非"能用就行"。

执行含义：
- 不以"小程序惯例"为借口降低标准（如系统默认红点、默认占位图、无反馈按钮均属不达标）
- 每页完成后按第六章《品质自检与持续优化》的八维量表打分，未达标不进入下一页
- 对标参考：Awwwards 获奖作品中的编辑式排版（editorial typography）、大胆留白、物理感动效，而非国内小程序的"组件堆叠"风

### 参考基准：Heritage Grove 式「水墨编辑风」（取神不取形）

评审中确认的参照样本：手绘青绿山水 + 奶油纸底 `#EAE3DE` + 墨青 `#175A67` + 编辑式字标 + 逐元素 stagger 入场。与本方案方向高度同频（墨青≈青绿、奶油纸≈宣纸米白、水墨山水≈云纹图形），作为**品质与氛围的对标基准**。但不照搬其三件事：拉丁双字体体系（对中文无效）、视频全屏背景（小程序性能与信息流密度不允许）、匠人品牌的冷峻气质（学生社区需要活力与亲近感）。

从该样本提取并已并入本方案的四点：

1. **色彩纪律**：纸底 + 单一墨色的克制——元信息灰阶由 4 级（text1–text4）收敛为 3 级，合并 text3/text4
2. **水墨山水主视觉**：以"手绘青绿山水"为方向生成**静态插画**（不用视频），用于登录页、身份卡、空状态三处品牌位
3. **入场动效编排**：`rise` 逐元素 stagger——`opacity + translateY(18rpx)`、70ms 步进、内联 `--i:N` 索引控制延迟（见 2.6），总时长控制在 900ms 内
4. **工程严谨度**：reduced-motion 降级、≥40px 触控热区、输入框 16px 防 iOS 聚焦缩放——已补入第六章量表检查要点

### 明确不做的

- 不改主色调（青绿是品牌色，问答蓝、打卡琥珀的语义色分工也保留）
- 不引入第三方 UI 库（现有自定义体系已成型，引入会破坏一致性）
- 不做深色模式（校园工具类小程序，投入产出比低，列入二期观察）

## 二、设计 Token 重构（所有页面的地基）

> **单位规则（最高优先级）**：本文所有实现值一律使用 rpx；px 仅用于描述设备物理指标（屏宽档位、热区物理尺寸）。换算锚点：16px = 32rpx、40px = 80rpx（375pt 屏）。借鉴自网站规格的数值必须换算后才能落地，禁止把 px 直接写入 WXSS。

### 2.1 间距网格

现状：大量 `25.5rpx / 61.5rpx / 72.5rpx` 等非整数（原型 px×1.275 直接换算残留），无规律可循。

**改为 8rpx 基准网格**，只允许：`8 / 16 / 24 / 32 / 40 / 48 / 64`。旧值就近取整（25.5→24，72.5→72），全局替换。

网格只管**布局间距**（margin / padding / gap）；组件内部装饰性微值（笔触高度、指示点直径、光池色带位置等）豁免，由对应契约单独规定。

### 2.2 圆角体系（同心规则）

现状：`--r-lg:36 / --r-md:25.5 / --r-sm:18` 与实际使用脱节，胶囊、卡片、内嵌元素圆角随意。

**规则：外圆角 = 内圆角 + 内边距**

| 层级 | Token | 值 | 用途 |
| --- | --- | --- | --- |
| 页面大卡 | `--r-xl` | 32rpx | 瀑布流卡、帖子卡、sheet 面板 |
| 内嵌块 | `--r-lg` | 24rpx | 卡内图片、卡内子模块 |
| 小组件 | `--r-md` | 16rpx | 标签、chip、输入框内元素 |
| 微元素 | `--r-sm` | 8rpx | 角标、迷你标签 |
| 全圆 | `--r-full` | 999rpx | 头像、药丸按钮、FAB |

### 2.3 阴影层级（替代边框思维）

现状：卡片靠 `border: 2rpx solid var(--line)` 撑边界，平。投影只有一组且极浅。

| 层级 | 值 | 用途 |
| --- | --- | --- |
| `--shadow-1` | `0 2rpx 8rpx rgba(14,59,46,.04)` | 列表行、静态卡 |
| `--shadow-2` | `0 36rpx 88rpx -52rpx rgba(14,59,46,.28)` | 瀑布流卡、弹层（负 spread 让大模糊收敛在元素正下方，不污染四周） |
| `--shadow-brand` | `0 12rpx 32rpx rgba(16,165,106,.28)` | FAB、主按钮、身份卡 |

边框保留给输入框和分隔线，卡片边界交给阴影。

### 2.4 字阶（编辑式排版，全站统一黑体）

全站使用系统黑体栈（`-apple-system / PingFang SC / Microsoft YaHei`），不内嵌任何定制字体。排版的高级感来自**字号对比、字重对比、字距控制**，而非字体本身。

| 级别 | 字号 | 字重 | 附加处理 | 用途 |
| --- | --- | --- | --- | --- |
| L1 | 48rpx | 800 | `letter-spacing: 2rpx` | 页面大标题（校园里的新鲜事 / 我的圈子 / 消息） |
| L2 | 36rpx | 800 | `letter-spacing: 1rpx` | 帖子标题、问答标题、sheet 标题 |
| L3 | 28rpx | 700 | — | 卡片标题、区块标题 |
| L4 | 26rpx | 400 | — | 正文 |
| L5 | 24rpx | 400 | — | 辅助正文、评论 |
| L6 | 20rpx | 400 | `letter-spacing: 1rpx`，小数字标签感 | 元信息（时间/赞数/人数） |

编辑式手法（获奖级排版的关键动作）：
- L1 大标题旁配一行 L6 级别的**大字距小标签**（如日期、栏目名），形成"巨大标题 + 极小注脚"的对比
- 正文加 `text-wrap: pretty`，标题加 `text-wrap: balance`（已部分存在，需全量）
- 所有计数数字保留 `tabular-nums`
- **光学对齐纪律**：图标与文字混排时做视觉居中校验，允许 ±2rpx 的手动修正（如 `padding-top: 1.5rpx`、svg 偏移 `top: -1rpx`）；以文字墨迹宽度（而非字号盒）评估对齐；同一行链接共享同一字号，禁止逐项微调

### 2.5 色彩微调

主色不动，补两个品牌色：

```css
--paper: #F7F3EA;        /* 宣纸米白：品牌底色点缀，用于大标题区块背景、空状态 */
--ink-brush: #2B4A3E;    /* 墨色：大标题专用色，比纯黑软 */
```

灰阶收敛（对齐参考基准的色彩纪律）：元信息灰阶由 4 级（`--text1`–`--text4`）收敛为 3 级，`--text4`（#BBC6BF）并入 `--text3` 并微调至可辨识度下限 `#8A9890`；占位符文字允许使用 `--text3` × 0.85 透明度（不占独立色阶）。

### 2.6 动效与材质 Token（吸收自 JungleMind 规格）

**全站唯二缓动**——默认曲线用于一切 transition/animation；回弹曲线仅注册给"必须弹跳"的反馈（点赞数字、FAB 按压回弹），除此之外禁止另立第三条：

```css
--ease: cubic-bezier(.16, 1, .3, 1);          /* 默认：expo-out */
--ease-spring: cubic-bezier(.34, 1.56, .64, 1); /* 仅回弹场景 */
```

**stagger 索引模式**——逐元素入场不再写 nth-child 延迟列表，改用内联索引变量：

```css
.rise{ animation: rise .9s var(--ease) both; animation-delay: calc(var(--i, 0) * 70ms); }
@keyframes rise{ from{ opacity:0; transform:translate3d(0, 18rpx, 0) } to{ opacity:1; transform:none } }
```

元素上只标 `style="--i:N"`（N 从 0 起，间距 70ms），只动 transform/opacity，不产生布局位移。

**滚动/拖拽联动的指数平滑**（吸收自滚动叙事站规格）——联动值不直接映射滚动位置，一律过 lerp：

```js
current += (target - current) * (1 - Math.exp(-dt * 8));  // 帧率无关：60Hz/120Hz 手感一致
if (Math.abs(target - current) < 0.002) current = target; // 吸附阈值，防末端抖动
```

适用：吸顶栏滚动渐变、进度环动画、拖拽跟手。禁止把 `scrollY` 直接映射到样式值（会抖、帧率敏感）。

**分层降级链 + 看门狗**——任何高级渲染方案必须声明完整降级路径，并配超时看门狗：

- 示例（磨砂材质）：`backdrop-filter` → 不支持时 `.65` 不透明度实底兜底（已内置）
- 示例（骨架屏）：加载超过 8s 未返回 → 切换为重试态，禁止无限呼吸
- 规则：降级链写在组件注释里，看门狗超时时长必须给出具体数值

**磨砂材质配方**——仅用于吸顶搜索框、AI 输入 dock 这类"背后有滚动内容"的悬浮件，禁止用在页面背景上：

```css
background: rgba(255,255,255,.65);                    /* 不透明度即安卓无 blur 时的兜底 */
-webkit-backdrop-filter: blur(18rpx) saturate(1.15);
backdrop-filter: blur(18rpx) saturate(1.15);
border: 2rpx solid rgba(14,59,46,.08);
box-shadow: inset 0 2rpx 0 rgba(255,255,255,.6);      /* 顶部高光 */
```

## 四、全站统一的五个改造动作（优先级最高）

这五项投入小、覆盖全部页面，做完整体观感立刻提升一档。

### 动作 1：封面图系统替换占位色块

为无图内容建立**分类渐变封面**（替代 `.tcover` 的色块+大图标）：

| 内容类型 | 封面方案 |
| --- | --- |
| 图文帖 | 按话题映射渐变 + 轻纹理（晚霞→橘粉渐变、图书馆→青蓝渐变），叠加细云纹 SVG |
| 问答 | 纯文字大卡：标题放大 + 摘要 + 回答数，**彻底去掉封面区** |
| 资料 | 文件类型色块缩小为左侧 96rpx 图标，右标题右摘要，不再占整封面 |
| 打卡 | 进度环已有，保留，缩小为行内元素 |

原则：**无图不硬凑图，文字排版本身就是封面。**

### 动作 2：统一 tab/筛选器的四种写法为一套

现状全站有 4 套互不相干的 tab 样式。统一为**「墨笔下划线」式**（墨笔触是绘制的 SVG 图形，不依赖任何字体，全用户可见）：

- 选中：文字 `--text1` 加粗 + 底部 6rpx 高手绘笔触形下划线（SVG 笔触，两端细中间粗，是全站第一个图形记忆点）
- 未选中：`--text3`
- 适用：发现页频道、圈子详情三段、问答排序、全部圈子分类
- 药丸实心样式只保留给"操作型"筛选（如"已加入/加入"状态）

### 动作 3：触感与动效规范

| 场景 | 规范 |
| --- | --- |
| 按压 | 已有 `.press/.press-sm`，补全遗漏组件（icard、mrow、ask-item 的 transform 反馈） |
| 列表进入 | 逐元素 stagger：`.rise` + 内联 `--i:N`（70ms 步进，`translate3d(0,18rpx,0)`，规范见 2.6）。作用域：**页面列表仅首次加载执行一次；弹层/面板每次打开都执行**（契约 4），总时长 ≤900ms |
| 弹层内容进入 | **遮罩升起**：子项包裹 `overflow:hidden` 容器，内容从 `translateY(115%)→0` 升起（发布面板四项、AI 页"大家都在问"列表适用） |
| 弹层进出节奏 | **慢进快出**：stagger 与逐项延迟只在打开态生效；关闭时所有子项同时收起，不做反向 stagger |
| 滚动联动 | 声明式**分段曲线**：动画状态写成进度 p 的分段函数（淡入窗 0.08 / 平台期 / 淡出窗 0.08，前段全退后段才进），不写定时器；联动值一律过指数平滑 lerp（2.6） |
| 吸顶栏明暗翻转 | 配色是滚动位置的函数：头图区白字透明底 → 滚过头图后翻墨色字 + 磨砂底，过渡 500ms。**首个应用场景：帖子详情页**（滚过 d-hero 后翻转） |
| 点赞/收藏 | 图标填色切换 + 数字 `scale(1.2→1)` 弹跳（200ms，用 `--ease-spring`，是全站回弹曲线的指定场景之一） |
| 加载 | 全站列表页统一骨架屏（灰绿 `#EDF4EF` 呼吸块），禁白屏 |
| 空状态 | 统一插画位（云纹 SVG）+ 一句引导文案 + 一个主按钮，三件套 |

以上所有动画/过渡统一使用 `--ease` / `--ease-spring`（2.6），不允许页面级自定义第三条缓动。

### 动作 4：状态语义色收口

未读红点（`--error` #FF5A5A）在消息、圈子、tab 栏到处是纯红。改为：

- 普通未读数：主绿胶囊白字
- 仅"@"、系统告警等强提醒保留红色
- 已赞/已收藏/已关注：主绿填色图标；未操作：线性灰图标

### 动作 5：光池按钮与徽标光带（像素级招牌工艺，吸收自 Vertex Shops 规格）

**光池按钮**：主按钮/FAB 底部积一段多段渐变"光池"，被按钮自身圆角裁切（`overflow:hidden` 是强制项），顶部加一条模糊发丝高光。不是发光、不是外投影、不是底边条——是光积在按钮内部底缘。

```css
.btn-primary{
  position:relative; overflow:hidden;                 /* overflow:hidden 不可省略 */
  background:linear-gradient(to top,
    #3ED09A 2rpx, #2BC78D 6rpx, #18B57C 12rpx,       /* 底部 12rpx 光池：最亮 */
    #10A56A 24rpx, #0D8A56 40rpx,                    /* 向上衰减 */
    #0B7E52 100%);                                    /* 顶部回归深主色 */
  box-shadow: inset 0 2rpx 0 rgba(255,255,255,.25);   /* 顶部高光，玻璃感关键 */
}
```

- 适用：FAB（`+`发布钮）、发布动态主按钮、问答发布按钮、`加入圈子` 按钮
- 色带 brightest 段固定贴底 2–6rpx，向上 40rpx 内衰减完毕，不允许贯穿整个按钮
- 按压态已有 `scale(.96)`，不再叠加亮度变化（光池本身已是视觉焦点）

**徽标光带**：badge 类元素（精华、热榜、AI 学伴入口卡）底部 18rpx 内铺 4–6 段渐微光带 + 1rpx 发丝描边：

```css
.badge-glow{
  border: 1rpx solid rgba(11,126,82,.18);
  background: linear-gradient(to top,
    rgba(16,165,106,.14) 0, rgba(16,165,106,.07) 4rpx,
    rgba(16,165,106,.03) 8rpx, rgba(255,255,255,.01) 18rpx);
}
```

- 适用：`.badge.hot`（精华）、AI 学伴入口卡、热门圈子封面下缘
- 禁止给 badge 加外发光/外投影——光带只在内部

## 六、品质自检与持续优化（八维量表）

每个页面改版完成后，按以下八个维度自检打分（每项 1–5 分），**单项 ≤3 分即视为不达标，必须优化后复测，直到没有明显可提升之处方可验收**。每期满分 40 分，验收线 34 分。

| 维度 | 5 分标准（获奖级） | 1 分表现（现状常见） | 检查要点 |
| --- | --- | --- | --- |
| **排版** | 字阶严格、字距控制到位、标题 balance / 正文 pretty、数字等宽、图标文字混排做光学居中 | 字号随意、层级对比弱、孤儿字、几何居中但视觉歪斜 | 任意截图能否说出每个字号属于 L1–L6 哪一级；抽查 3 处图标+文字混排，是否有视觉偏移 |
| **留白** | 留白有节奏感，疏密对比大胆；首屏信息完整利用 | 大片无意义空白（AI 页、圈子详情下半屏）或拥挤无呼吸 | 首屏截图：空白是否"有设计意图"还是"没做完" |
| **视觉层级** | 三层以上清晰层级（主题/内容/元信息），视线动线明确 | 全页同字号同灰度平铺 | 眯眼测试：眯眼看截图能否 1 秒内找到主标题和主操作 |
| **色彩** | 主色/语义色/中性色各司其职，状态色全站一致 | 红点滥用、灰度层级不足、对比度不达标 | 统计一页内出现的颜色数，超过 6 种需说明理由 |
| **动效** | 动效有物理感（缓出曲线、可中断）、stagger 编排；交互反馈 150–300ms，入场编排 ≤900ms（两类时长不混淆）；提供 reduced-motion 降级 | 无动效或线性匀速动效 | 逐个数页面内的动画，匀速 linear 的一律返工；开启系统减弱动效后检查降级 |
| **微交互** | 所有可点元素有按压反馈且热区 ≥80rpx（40px）；赞/藏/关注有状态切换动效；加载有骨架屏；输入框字号 ≥32rpx（16px，可读性下限，为字阶表外的功能性例外） | 点击无响应感、白屏等待、按钮无状态 | 随机点 10 个可点区域查反馈与热区；对照字阶表检查输入框字号例外是否被滥用 |
| **响应式** | 不同屏宽/刘海屏/安全区全部适配；横滑不裁切；长文不溢出 | 卡片被屏幕边缘裁切（热门圈子）、文字溢出悬挂（校园币） | 320px 小屏 + 大屏各截一遍，检查裁切与溢出 |
| **原创性** | 有记忆点细节（墨笔触下划线、云纹渐变、编辑式大小标题对比），不与模板撞脸 | 看起来像任何一款社区小程序 | 遮住 logo 给第三人看，能否认出是"青云" |

### 自检流程（每页执行）

1. 改版完成 → 真机/模拟器截图（首屏 + 滚动态 + 交互态各一张）
2. 对照八维量表逐项打分，记录扣分项
3. 扣分项全部修复 → 复测
4. 全部 ≥4 分 → 该页验收通过；仍有 ≤3 分项 → 返回步骤 3，直至没有明显可提升之处

### 断点验收清单（吸收自 JungleMind §15，每页必过）

打分之外，每页还需通过以下硬性检查（任一不满足即返工，不接受"酌情"）：

- [ ] 320 / 375 / 414px 三档屏宽均无横向滚动条
- [ ] 320px 小屏：页面标题、返回键、右侧操作位两两不碰撞
- [ ] 吸顶/吸底栏（tabbar、输入 dock、操作栏）：背后内容滚动过时磨砂材质生效，且安全区 `env(safe-area-inset-*)` 避让正确
- [ ] 所有输入框字号 ≥32rpx（=16px，可读性下限；注：小程序 input 聚焦不触发页面缩放，此条为可读性而非防缩放）
- [ ] 所有可点元素热区 ≥80rpx（=40px）
- [ ] 长文案边界：标题 20 字、正文 200 字、用户名 12 字的极端数据下不溢出、无孤儿字
- [ ] 系统字体换成宽字形字体（如楷体）后，标题容器不截断、不换行错乱
- [ ] 开启系统"减弱动态效果"后：stagger/遮罩升起关闭，功能与布局完整可用

### 持续优化机制

- 每期结束后整站走查一遍八维量表，防止页面间标准漂移
- 量表扣分记录归档到 `.mimosa/reports/`，作为迭代依据

## 七、像素契约（Pixel Contracts）

吸收自 Vertex Shops 规格的治理方式：**招牌组件一旦定稿，写出像素契约 + DO-NOT 清单**，后续任何迭代不得"顺手优化"它们。契约组件的修改必须走方案修订，不允许散在页面里被局部覆盖。

### 契约 1：光池按钮（FAB / 主按钮）

必须满足：底部光池贴底 2–6rpx 最亮、40rpx 内衰减完毕；`overflow:hidden` 裁切圆角；顶部 2rpx 内嵌高光。

DO NOT：
- 不加任何外发光/光晕；**唯一允许的外阴影是 `--shadow-brand`**（FAB 的品牌投影），其余 outer box-shadow 模糊半径 ≤8rpx 且透明度 ≤10%
- 不用双色简单渐变替代多段光池，不用 `border-bottom` 或独立色条模拟
- 不让光池溢出按钮圆角，不删除 `overflow:hidden`
- 不给按压态叠加亮度变化（只保留 `scale(.96)`）

### 契约 2：墨笔触 tab 下划线

必须满足：SVG 手绘笔触、两端细中间粗、高 6rpx、仅选中项显示；未选中项纯 `--text3` 文字无任何装饰。

DO NOT：
- 不改成实心药丸/色块选中态（那是第四套 tab 样式的回潮）
- 不用直线或等宽圆角矩形替代手绘笔触
- 不给 tab 加背景色、描边或投影

### 契约 3：水墨山水主视觉（登录页 / 身份卡 / 空状态）

必须满足：手绘青绿山水静态插画、宣纸米白底、文字直接排布在画面上（不加深色遮罩）。

作用域：仅覆盖登录页、身份卡、空状态三处**水墨插画品牌位**。帖子头图等用户照片场景不在本契约内——该场景的文字可读性由"吸顶栏明暗翻转 + 磨砂底"（动作 3）兜底。

DO NOT：
- 不加视频背景（性能与信息流密度不允许）
- 不在插画上叠渐变遮罩/模糊/暗化层
- 不用写实照片或 3D 渲染图替代手绘水墨方向

### 契约 4：发布面板（sheet）遮罩升起

必须满足：面板本体滑入后，四个发布项从各自 `overflow:hidden` 遮罩内 `translateY(115%)→0` 升起，stagger 70ms 步进（`--i` 索引）；关闭时全部同时收起，无反向 stagger；全程只用 transform/opacity。

DO NOT：
- 不给关闭态加逐项延迟（慢进必须快出）
- 不用 opacity 淡入替代遮罩升起（两者是不同手法，不混用）
- 不让子项动画位移超过遮罩容器（溢出即破功）
- 不在动画中触碰 width/height/margin 等布局属性

## 八、风险与注意

- **间距取整是全局替换**：25.5→24 等改动会影响所有页面布局，需逐页截图回归，建议配合真机走查
- **系统字体可变性**：小程序跟随用户手机系统字体（如用户把系统换成楷体/书法体，全站字体都会变）。排版必须对此鲁棒：行高、行数截断（-webkit-line-clamp）、容器尺寸不能依赖精确字形宽度，所有标题容器都要按"字形变宽 20%"做容错验证
- **渐变封面映射**：话题→渐变的映射表需集中放在 `data/` 或常量文件，避免散在各页面
