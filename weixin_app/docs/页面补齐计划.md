# 青云 2.0 · 缺失页面补齐计划

> 12 个页面，5 个实施批次。设计总纲沿用已定稿的四条产品原则：
> **① 列表即卡片**（信息密度让位于扫读效率）；**② 表单少而深**（每屏只问一件事，底部常驻主操作）；
> **③ 全站统一**（--qd 令牌、16px 节奏、hover 触感、右滑子页/上滑弹层双动效、右上胶囊区留白）；
> **④ Mock 与后端字段 1:1**（页面数据结构 = 接口文档响应结构，单点切换）。

---

## 批次 A · 发布链路（最高频动线）

### A1. pages/post-create 发布表单（发动态 / 提问题，双模式）
- **入口**：半屏面板"发动态/提问题"（`mode= post|qa` 参数区分）。
- **结构**（上滑弹层式页面）：
  - 顶栏：‹ 返回 + 标题（发动态 / 提问题）+「存草稿」文字钮；
  - 主体 scroll：多行文本区（自动增高，占位文案随模式变化）→ 图片九宫（+3 上限 9，含删除角标）→ 圈子选择行（横向胶囊多选，来自 `getSpaces`，默认上次发布圈子）→ 话题输入（chip 式回车成标签，qa 模式换为**标签+悬赏滑条**：0/5/10/20 校园币档位）；
  - 底部常驻 bar：`发布` 主钮（primary 满宽 88rpx 高）+ 字数 0/2000。
- **精致点**：发布钮在空内容时置灰 40%；图片 hover 删除角标放大；提交成功 toast + 返回。
- **数据**：`createPost`（V1 有）；悬赏字段 qa 模式附加。

### A2. pages/resource-upload 传资料
- **入口**：半屏面板"传资料"。
- **结构**：文件选择卡（大虚线区，点击唤起 wx.chooseMessageFile）→ 识别结果卡（文件名/大小/类型图标 + **AI 课程识别结果**"检测到：数据结构 → 已归入"可改）→ 权限选择（公开/圈内/仅自己 三段）→ 描述文本区 → 发布。
- **数据**：`resources/upload` + `aiRecommendTags`（识别）。

## 批次 B · 打卡闭环（核心留存功能）

### B1. pages/checkin 打卡主页
- **入口**：半屏"去打卡"、发现页打卡卡。
- **结构**：页头"今日打卡"摘要（已 x/y + 连续天数大数字）→ **我的挑战**横滑卡（进度环+今日状态：已打卡✓/待打卡/已断）→ **全部挑战**列表（分类 chips：全部/学习/运动/习惯）→ 底部"发起挑战"入口。
- **数据**：`getChallenges` + `getRecords`（我的状态聚合）。

### B2. pages/checkin-detail 挑战详情
- **结构**：挑战头卡（名称/发起人/成员头像列/周期/规则）→ 大进度环（我的 x/y 天 + 连续火焰）→ **今日打卡**主按钮（已打卡态变为分享战绩）→ 动态时间线（成员打卡流：头像+内容+时间，3 条预载更多）。
- **数据**：`getChallengeById` + `checkin` + `shareCheckinRecord`。

### B3. pages/checkin-create 发起打卡
- **入口**：打卡主页、圈子打卡栏空态。
- **结构**：挑战名 → 目标拆解（AI 建议按钮：输入"背单词"自动生成"每天 50 词"节奏，用 `aiChat`）→ 周期选择（7/14/21/30 段选 + 自定义）→ 提醒时间 → 可见范围（公开/圈内）→ 发起。
- **数据**：`createChallenge`。

## 批次 C · 资料链路

### C1. pages/resources 资料广场
- **入口**：频道"资料"、圈子资料栏"全部"。
- **结构**：搜索条 → 分类 chips（全部/讲义/真题/笔记/模板）→ 排序（最新/最热）→ 资料卡列表（左侧类型色块图标 PDF/XLS/DOC，右侧下载/收藏，角标下载次数）。
- **数据**：`getResources`（V1 有分页）。

### C2. pages/resource-detail 资料详情
- **结构**：头卡（类型图标/文件名/上传者/大小/版本/下载次数）→ **预览区**（scroll-view 渲染 `getResourcePreviewText` 前 N 段 + "下载查看完整版"）→ 简介 → 相关资料推荐 2 条 → 底部 bar：收藏 ☆ + 下载 ➤（主钮，调用 `getDownloadUrl`）。
- **数据**：`getResourceById` + `getPreviewUrl` + `getDownloadUrl`（V1 齐全）。

---

## 批次 D · 搜索与个人域

### D1. pages/search 全站搜索
- **入口**：发现页/圈子页搜索条。
- **结构**：自动聚焦搜索框（返回钮 + input + 清除）→ 空态：**热搜词**（chip 云）+ 搜索历史（本地存储，可清空）→ 结果 tabs（全部/帖子/资料/圈子/用户）→ 结果分组列表（复用现有卡组件样式）。
- **数据**：`search`（V1 返回 SearchResult 聚合）。

### D2. pages/user 他人主页
- **入口**：任何头像/作者名。
- **结构**：头部身份卡（复用 mine 的 idcard 样式但浅色版 + 关注按钮态）→ tabs（动态/资料/打卡）→ 列表复用。
- **数据**：`getUserById` + `getPosts`?userId= + `isFollowing` + `follow`。

### D3. pages/follows 关注·粉丝
- **结构**：tabs 关注/粉丝 + 用户行（头像/昵称/签名 + 互相关注标记 + 关注按钮三态）。
- **数据**：`getUserFollowing` / `getUserFollowers`。

### D4. mine 子页：我的收藏 / 我的资料
- **结构**：mine 入口直接进对应列表页（收藏=PostVO 卡列表；我的资料=resources 列表过滤 uploader=me）。
- **数据**：`getFavorites` / `getResources?mine=1`。

---

## 批次 E · 圈子创建与登录

### E1. pages/space-create 创建圈子
- **结构**：封面选择（纯色/渐变预设 6 宫，点击预览大图）→ 圈名（≤12 字）→ 分类（学习/考研/生活/兴趣）→ 简介（≤50 字）→ 公开性 → 创建。
- **数据**：`createSpace`。

### E2. pages/login 登录（+ 注册/忘记密码 三模式）
- **结构**：品牌头（青云 logo 字 + slogan）→ 账号密码登录卡 → 底部"验证码登录/注册/忘记密码"文字链切换；微信一键登录主按钮（wx.login 静默）。
- **数据**：`login` / `sendEmailCode` / `register` / `forgotPassword`（V1 齐全）。
- **策略**：游客可浏览（现有页面不动），发布/关注/私信等写操作触发跳登录。

---

## 执行约定（每页交付标准）

1. 样式走全局令牌，禁止页内魔法数（复用 build.js 产物 + 页面级 wxss 仅放布局细节）；
2. hover-class 触感全覆盖（press / press-sm / press-bg）；
3. 状态栏 sb 注入、右上胶囊区留白、底部安全区；
4. 数据一律 `data/*.js` 种子（结构=接口文档响应），页面 js 只做视图逻辑；
5. 每批完成：WXML 配平 + JS 语法 + handler 死链扫描 + IDE 重载。

**顺序**：A → B → C → D → E，与用户动线频率一致。
